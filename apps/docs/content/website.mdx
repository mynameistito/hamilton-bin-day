The [Hamilton Bin Day website](/) looks up a collection schedule for a Hamilton street address. It works in a desktop or mobile browser and can be installed as a progressive web app (PWA).

## Look up an address

1. Open the [home page](/) and enter a Hamilton street address.
2. Select the matching address from the suggestions when prompted.
3. Review the next collection date, collection day, and bins to put out.

An optional link such as `/?query=1+Grey+Street` pre-fills the address and runs the lookup automatically. You can also open the home page without a query and enter an address yourself; addresses entered in the search form are not added to the page URL. Search-engine or browser custom shortcuts (sometimes called “search bangs”) can use the URL template `https://bin-day.mynameistito.com/?query=%s` if they support custom search URLs. Set up the shortcut in your search engine or browser; it is not required to use the site.

If the address is not matched, refine the search and choose one of the suggested addresses. The lookup depends on Hamilton City Council's public service, so it may be unavailable if that service is down.

## Understand the schedule

The result shows the next collection and the following alternating week. Food scraps are collected every week.

| Week        | Put out                                                |
| ----------- | ------------------------------------------------------ |
| Red week    | Red rubbish bin and food scraps bin                    |
| Yellow week | Yellow recycling bin, glass crate, and food scraps bin |

Dates come from the Council lookup and may change, including around public holidays. Check [official Council collection information](https://hamilton.govt.nz/) if you need to confirm a change.

## Use the sorter and reminders

- [What goes where?](/what-goes-where) searches the Council's public sorter catalogue for disposal guidance.
- Bin-day reminders can send a push notification while the app is closed. Enable reminders from the website and choose a lead time and local delivery time. A fresh lookup updates the saved schedule; exceptional Council date changes require another lookup.
- On iPhone or iPad, install the site from Safari's **Add to Home Screen** option before enabling push reminders. Browser support and notification permission affect availability.

Reminders do not save your address on the server. For details about data handling, see the [Privacy Policy](/privacy/).
