The `@hamilton-bin-day/cli` package provides a command-line client for the same public Hamilton City Council lookup used by the website. It requires Node.js 22 or newer.

## Run without installing

Use `npx` to run the latest published package:

```sh
npx @hamilton-bin-day/cli schedule "12 Grey Street"
```

Or install it globally with your package manager, then run `hamilton-bin-day`:

```sh
npm install --global @hamilton-bin-day/cli
hamilton-bin-day schedule "12 Grey Street"
```

## Commands

```sh
hamilton-bin-day search "12 Grey Street"
hamilton-bin-day lookup "12 Grey Street"
hamilton-bin-day schedule "12 Grey Street"
hamilton-bin-day --version
```

- `search` returns matching Council addresses.
- `lookup` resolves the address and returns a schedule, or suggestions when there is no exact match.
- `schedule` returns the same resolved schedule (it also returns suggestions if no match is found).
- Address words are joined together, so quoting a multi-word address is recommended. Common street-type and unit-letter variants are normalized during matching.

JSON is the default output, suitable for scripts and other tools. Use `--text` (also `--pretty` or `-p`) for a readable terminal summary. `--json` or `-j` explicitly selects JSON.

```sh
hamilton-bin-day schedule "12b Grey Street" --text
hamilton-bin-day lookup "12 grey st" --json
```

The primary executable is `hamilton-bin-day`. The deprecated `hcc-bin-day` alias remains available for existing scripts; use `hamilton-bin-day` for new usage.

A successful JSON schedule result includes `found`, `matchedAddress`, and `schedule`. The schedule contains the next and following collections, dates, collection day, and the bins for each week. An unmatched query includes `found: false` and a `matches` array. Council request failures are written to stderr and exit with a non-zero status.

## Data and availability

The CLI calls Hamilton City Council's public lookup API directly. It does not need an API key or a Hamilton Bin Day account. Requests depend on the Council service being available, and returned schedules can change. See the [main website](/) for the browser experience or the [MCP guide](/docs/mcp/) for AI clients.
